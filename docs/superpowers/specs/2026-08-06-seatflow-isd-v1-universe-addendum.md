# SeatFlow-ISD V1.0 龙虎榜股票池补充口径

本补充口径由用户于 2026-08-06 明确，优先于原设计中可能包含关联传播股票的宽口径。

- 数据集只包含 2023-01-03 至 2026-08-06 期间至少出现过一次龙虎榜摘要记录的股票。
- 一只股票只要上榜一次，就进入 `lhb_stock_universe`。
- 保留股票的全部龙虎榜事件，以及每个事件周期从 D0 到续期后 D+5 的全部 DIRECT 样本。
- 本版本不生成 SPILLOVER 或关联股票样本，也不输出从未上榜股票的市场事实。
- 全市场日行情和 daily-basic 快照可以作为源数据读取，但写入数据集前必须过滤到 `lhb_stock_universe`。
- 已落盘且哈希、行数校验通过的同源全市场行情不重复抓取；“都要爬取”的完整性由全日期龙虎榜事件抓取，以及龙虎榜股票周期所需行情/基础数据覆盖共同证明。
