# SeatFlow R3：8GB GPU 稳定性优化计划

本仓库执行附件计划时采用以下强制边界：

1. 先检查 R2 的 3 folds × 5 seeds 证据；若全部门禁通过，停止优化并冻结。
2. 若证据不存在或未通过，只执行首轮 Task 22–25。
3. 首轮包括：冻结 R2、稳定性归因、建立未污染 R3 协议、测试截面标准化标签与
   LambdaRank@5。
4. 首轮不实现 GRU、席位动态画像、FiLM、EMA/关系 dropout/一致性、Top-5 margin
   或超图。
5. 单张 8GB GPU，五种子串行，一次一张日期图，峰值显存不超过 7.2 GiB，
   参数量不超过 5M。
6. R3 内层固定为 2 folds × 3 seeds，最多比较 5 个新增配置；唯一候选才可进入
   3 folds × 5 seeds 完整验证。
7. 完整验证之后不得继续在相同外层折上微调；future-blind 只接收一个冻结模型。

Task 25 只比较 L0、L1、L2 三种固定目标。新标签必须在每个交易日内部进行
1%/99% winsorize、z-score 和 rank percentile，不允许跨验证期或测试期拟合统计量。
L2 的 LambdaRank@5 只采样真实前 20% 对其余股票，以及预测排名 1–10 附近的边界
股票对；每个日期最多 1024 对，禁止构造完整 N² 排序矩阵。

只有 Task 25 在固定内层协议中明确优于 R2，才允许进入 Task 26–30。
