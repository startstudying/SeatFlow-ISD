## Task 23：稳定性归因

新增纯标准库分析器，支持按日期、fold 和种子对计算：

- Pearson / Spearman；
- Top-5 / Top-10 Jaccard；
- Rank 5/6 score margin；
- 同一股票跨种子的每日预测标准差；
- fold 和市场状态汇总；
- A–F 多标签失败分类与关系消融输入。

分析器对当前 R2 工件返回 `insufficient_evidence`，且 `failure_classes=[]`。这是
失败关闭行为，不将“缺少证据”误判为标签错配。

## Task 24：未污染协议

R3 内层固定 2 folds × 3 seeds，最多 5 个新增配置；最终验证固定 3 folds ×
5 seeds。选择采用逐级门禁，优先最差 fold、种子方差和 Top-5 重合率。GPU 峰值上限
7.2 GiB，参数量上限 5M，种子必须串行。

## Task 25：标签与排序目标

- 每个 `(交易日, horizon)` 独立执行 1%/99% winsorize、总体标准差 z-score 和
  平均秩 percentile；常数截面得到 `z=0`、`percentile=0.5`。
- 方向 BCE 明确使用二元目标 `residual_return > 0`，不把 `-1/0/1` 直接送入 BCE。
- L0、L1、L2 权重固定；L2 将回归 z-score 与排序 percentile 分开传入。
- LambdaRank@5 只构造真实前 20% 对其余股票，以及预测 top-5 对 rank 6–10 的
  边界对；每个日期最多 1024 对，不构造 N² 矩阵。
- L2 已在真实 CUDA 路径完成一轮反向传播、优化、保存和显存释放。
